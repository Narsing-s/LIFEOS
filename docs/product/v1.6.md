# LIFEOS V1.6 — Connected Life

V1.6 closes the main gap between the LIFEOS data model and a usable connected-life product.

## Included

- Google OAuth connection with encrypted access/refresh tokens.
- Background sync worker with token refresh support.
- Google Calendar events -> Life Timeline.
- Google Drive files -> Life Timeline.
- Gmail metadata -> Universal Inbox.
- Sync run lifecycle: queued -> running -> completed/failed.
- Sync history and life overview API endpoints.
- Web workspace tabs for Timeline, Inbox, Finance, Automations, Integrations and Settings.
- One-click Google connect and sync controls.

## Operational requirements

Set `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`, `GOOGLE_REDIRECT_URI`, `DATABASE_URL`, `REDIS_URL` and a strong production `JWT_SECRET`.

Run the sync worker alongside the API:

```bash
pnpm --filter @lifeos/sync-worker build
pnpm --filter @lifeos/sync-worker start
```

The worker intentionally stores only metadata for imported Gmail/Drive/Calendar records. Provider access tokens remain encrypted. Provider disconnect removes the LIFEOS connection and stops future sync jobs.

## Remaining provider work

Google Photos and Contacts are represented in the integration architecture but require their provider-specific APIs/scopes and product verification before production import is enabled. They should be added as isolated adapters rather than mixed into the core sync loop.
