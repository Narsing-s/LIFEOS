# LIFEOS V1

## Goal

Deliver a useful personal operating system around five excellent capabilities: smart documents, universal search, personal memory, tasks/reminders, and an AI life assistant.

## Included

- Account registration/login/session management
- Personal profile and preferences
- Responsive personal dashboard
- PDF/image document upload
- Document classification and metadata extraction
- OCR-ready asynchronous processing pipeline
- Universal search across supported LIFEOS resources
- User-controlled memories
- Tasks and reminders
- Asset and warranty tracking
- AI assistant with retrieval and source citations
- AI actions through explicit tools
- Activity history and audit logging
- PostgreSQL + pgvector foundation
- Redis/BullMQ background jobs
- Docker local infrastructure
- OpenAPI v1 contract
- Unit/integration/E2E test foundation
- CI/CD foundation

## Explicitly deferred

Banking integrations, email/calendar synchronization, WhatsApp/social integrations, voice assistant, desktop application, collaboration, autonomous agents and complex financial analytics.

## Product loop

Capture -> Understand -> Connect -> Search -> Ask -> Act -> Remember

## Acceptance examples

1. Upload a receipt and later search for the merchant or purchased item.
2. Ask when an asset warranty expires and receive a source-backed answer.
3. Tell LIFEOS to remember a fact and retrieve it later.
4. Create a reminder through natural language.
5. Ask a cross-domain question and receive related documents, memories, tasks or assets.
